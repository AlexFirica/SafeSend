# AI Risk Engine

## 📌 Descriere
Acest proiect simulează un sistem de securitate care analizează comportamentul utilizatorilor la login și detectează posibile riscuri.

Sistemul primește date despre utilizator (IP, browser, OS, timezone etc.) și calculează un scor de risc.

Rezultatul final este:
- 🟢 Green = sigur
- 🟡 Yellow = suspicios
- 🔴 Red = periculos
